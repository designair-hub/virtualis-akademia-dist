# Oklevél betűtípusok (TCPDF)

Az oklevél-PDF (`includes/Certificates/CertificateRenderer.php`) a felület
betűtípusait használja, a LearnDash-be csomagolt TCPDF formátumára konvertálva
(`TCPDF_FONTS::addTTFfont`, TrueTypeUnicode):

| Fájl | Forrás | Licenc |
|---|---|---|
| `montserratextrab`, `montserratb` | Montserrat ExtraBold / Bold (JulietaUla/Montserrat) | SIL OFL 1.1 – `OFL-Montserrat.txt` |
| `inter`, `intersemib` | Inter 4.1 Regular / SemiBold (rsms/inter) | SIL OFL 1.1 – `OFL-Inter.txt` |
| `jetbrainsmonomedium` | JetBrains Mono Medium | SIL OFL 1.1 – `OFL-JetBrainsMono.txt` |
